# Lote

Daily German training for people who want a job in Germany: live classes, an AI speaking partner, vocabulary, grammar, writing and mock exams. €149/month.

- **`app/`**: the product, a working web app. See [`app/README.md`](app/README.md) to run it and put it online.
- **`PLAN.md`**: the business plan and 8-month profit model.
- **`index.html`**: a standalone waitlist landing page, if you want to collect sign-ups before launching the app.
